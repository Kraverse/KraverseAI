# KraVerse AI

Personal AI-powered portfolio and knowledge assistant for Kartik Katke.

## Vision

KraVerse AI combines a professional AI/ML portfolio with a grounded personal assistant that can answer questions about Kartik's projects, GitHub repositories, skills, education, and approved knowledge.

## Planned architecture

- Next.js / React portfolio and chat interface
- Python / FastAPI backend
- Retrieval-Augmented Generation (RAG)
- Local LLM inference with Ollama
- Local embeddings and vector storage
- GitHub repository ingestion and synchronization
- Optional online/free-tier model fallback
- Interview preparation mode

## Modes

- **Portfolio mode:** public, verified information suitable for visitors and interviewers.
- **Developer mode:** detailed project and codebase knowledge for authorized local use.
- **Interview Prep:** practice questions and feedback based on actual projects.

## Development principle

Keep the system simple, grounded, privacy-conscious, and easy to run locally. Avoid unnecessary abstractions and dependencies.

## Status

Early development. The repository is being built incrementally, starting with the portfolio and assistant foundation before connecting the real local LLM and RAG pipeline.
