# Project Knowledge

## DhobiXpert
A production-ready web platform built for a laundry startup. It is used as evidence of shipping and deployment experience.

## HelpDesk AI
An enterprise RAG assistant project. The project is part of Kartik's Generative AI portfolio and focuses on retrieval-augmented responses over project knowledge.

## Context Transfer
A browser-extension project concept for transferring AI conversation context between services when a conversation reaches a limit or needs to move to another assistant.

## ChurnIQ-ML
A machine-learning customer churn prediction project. The project uses a customer churn dataset and evaluates classification models using ROC-AUC and related metrics.

## KraVoice
A Streamlit-based audio transcription application with support for transcription workflows and downloadable text/subtitle outputs.

## KraVerse AI
A personal AI assistant intended to live inside Kartik's portfolio. It combines project/personal knowledge retrieval with a configurable LLM provider, supporting local Ollama inference and an online API mode.
